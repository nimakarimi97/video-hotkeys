# Security Policy

## Supported Version

Security fixes are applied to the latest version of Video Hotkeys.

## Reporting A Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository. If that option is unavailable, contact the maintainer through [nimakarimi.me](https://nimakarimi.me).

Include the affected version, reproduction steps, potential impact, and any suggested mitigation. You should receive an initial response within seven days.

## Scope

Useful reports include unintended page access, unsafe handling of page content, permission concerns, and ways to execute untrusted code in the extension context.
